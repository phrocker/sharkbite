03 / THE ENGINE

Still the Accumulo client.
Now also the engine.

Sharkbite began as a native Accumulo client. The Shoal engine underneath it reads and writes byte-compatible RFiles, runs standalone with no ZooKeeper, and keeps the Go, C, and Python client surfaces.

Embedded sorted key/value

shoal-embed is a standalone engine with a WAL, memtable, splits, flush, and compaction. RFile or Parquet tablets. No cluster required.

go run ./cmd/shoal-embed init \
  --table graph --data ~/.shoal/data
go run ./cmd/shoal-embed write \
  --table graph --data ~/.shoal/data < mutations.jsonl

Accumulo 4 client, three languages

A Go client, a stable C ABI with capability negotiation, and the shoal-sharkbite Python distribution, which installs the familiar sharkbite and pysharkbite imports.

python -m pip install ./python

from sharkbite import Client

Cluster roles, when you need them

Read-optimized scan server, tablet server, and compactor roles speak Accumulo-native protocols, with fenced WAL authority and offline major compaction. Validation status for each role is tracked in FEATURES.md.
