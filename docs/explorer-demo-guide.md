# Shoal Explorer Demo Guide

The Explorer demo starts from a clean checkout and stores all generated state
in `.shoal/explorer-demo`.

## Ingested knowledge

The ingest step stores UTF-8 Markdown as a revisioned document with sections
and exact source spans.

## Promotion gate

Run the canary validation before promotion and keep the exact citation in the
release note.

### Relationship target

Connect this guide to the release checklist so neighbors show an
application-defined relationship.
