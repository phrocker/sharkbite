# Authorized collector material for decision admission

`internal/collectorregistry.NewMaterialResolver` composes the collector registry with a mandatory `MaterialAuthority`. It resolves a bounded selected batch of registered observations into detached registration, enrollment, artifact-reference and observation metadata. It performs no writes, returns no original artifact bytes, and grants no inference or training permission.

`Resolve(ctx, purposeID, observationIDs)` requires actual caller domain Read permission plus a separate authority. `Authorize` gates per-source and purpose access before reading storage and rechecks after IO, including failures. `Verify` checks the resolved batch jointly after all registry reads; it must complete its own policy IO before deciding current source access and combined disclosure. It receives nil on incomplete resolution, which must never be interpreted as a complete empty source inventory. All-or-nothing output prevents a partial authorized prefix or count from becoming a successful response.

The first version accepts at most 64 unique observation IDs and budgets aggregate raw registry reads at 16 MiB. It checks each row's original stored domain, exact collector generation and current enrollment, immutable enrollment readback, artifact reference binding and receipt-time ordering. It compares current registration rows again before final authority verification. No registration read follows that verification; this provides a checked snapshot, not an authorization lease or repository-wide completeness claim.

Only the current enrollment is supported. An observation from a superseded enrollment is unavailable through this resolver even if its collector generation is unchanged. The current enrollment supplies the trustworthy immutable-row locator; historical lookup requires a separate index design. Existing `ReadObservation`, `Source` mapping and collector HTTP routes are unchanged.

The returned `Material` can be passed to `collectorregistry.Source` with an authority-policy ID approved by the host. The existing mapper preserves collector origin, provisioned control and policy, and attaches an attestation only when its verified window covers both observation and receipt time. Attestation establishes neither source truth nor independent corroboration.

A later request-registration service must obtain bounded original bytes separately, verify their exact recorded artifact digest and size, and retain them in the decision artifact catalog. Extractor payloads are not substitutes for original bytes. The resolver never fetches collector-named locations. Current task/source purpose and joint-disclosure checks remain mandatory during registration and subsequent evaluation, even when all content hashes match.
